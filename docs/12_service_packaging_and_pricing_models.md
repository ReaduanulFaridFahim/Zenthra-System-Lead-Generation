## 12.1 The Three-Tier Productized Packaging Model

Zenthra productizes its services into three clear engagement tiers to eliminate ambiguous quoting, accelerate deal velocity, and secure high recurring gross margins:

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                      THE PRODUCTIZED SERVICE LADDER                         │
├───────────────────┬──────────────────────┬──────────────────────────────────┤
│ Tier Level        │ Purpose & Scope      │ Price Range & Billing Structure  │
├───────────────────┼──────────────────────┼──────────────────────────────────┤
│ Tier 1: The Wedge │ Low-friction audit,  │ $3,500 – $6,500 (Fixed Fee,      │
│     Inroad Sprint │ POC, or scoping doc  │ 100% upfront or 50/50, 5–10 days)│
├───────────────────┼──────────────────────┼──────────────────────────────────┤
│ Tier 2: The Core  │ Production-grade     │ $12,500 – $65,000 (Fixed Milestones│
│     Implementation│ system deployment    │ 50% deposit, 25% mid, 25% signoff)│
├───────────────────┼──────────────────────┼──────────────────────────────────┤
│ Tier 3: Strategic │ Ongoing optimization,│ $1,500 – $6,000 / month          │
│     Retainer SLA  │ data support & tuning│ (Monthly recurring, auto-renewal)│
└───────────────────┴──────────────────────┴──────────────────────────────────┘
```

## 12.2 Exhaustive Service Line Pricing & Deliverable Specifications

### 1. Microsoft Power BI & Reporting Modernization
- **Tier 1: 5-Day Executive KPI Sprint (\$3,500)**
  - *Ideal Buyer:* CFO, VP Finance.
  - *Deliverables:* Ingestion of primary Excel workbook; automated Power Query ETL; clean star-schema data model; 3-page interactive Power BI dashboard (Executive Overview, Margin & P&L Analysis, Operational Trends); row-level security setup; 1-hour executive handover recording.
  - *Duration:* 5 business days.
  - *Estimated Delivery Hours:* 18–24 hours | Gross Margin: 78%.
- **Tier 2: Full Data Warehouse & Power BI Suite (\$15,000–\$28,000)**
  - *Deliverables:* Automated integration with ERP/accounting databases (NetSuite, Dynamics, SQL Server); multi-table dimensional modeling; 8–12 comprehensive departmental dashboards; automated scheduled gateway refreshes; mobile executive layout; user training workshops.
  - *Duration:* 4–6 weeks.
  - *Estimated Delivery Hours:* 80–120 hours | Gross Margin: 72%.
- **Tier 3: Managed BI & Reporting Retainer (\$1,500–\$3,500/mo)**
  - *Deliverables:* Up to 15 hours/month of custom report authoring, DAX performance optimization, gateway monitoring, and monthly schema updates.

### 2. AI Agents & Business Workflow Automation
- **Tier 1: Deterministic Workflow Automation POC (\$4,500)**
  - *Ideal Buyer:* COO, VP Operations, RevOps Director.
  - *Deliverables:* Current-state process map; design and deployment of 1 multi-step automated workflow in self-hosted n8n; API integration with 3 core platforms (e.g. CRM + Billing + Support); automated exception logging; live demonstration with verified >70% time reduction.
  - *Duration:* 10 business days.
  - *Estimated Delivery Hours:* 22–28 hours | Gross Margin: 76%.
- **Tier 2: Enterprise Multi-Agent Automation Engine (\$18,000–\$38,000)**
  - *Deliverables:* Full operational mapping; multi-agent network (triage agent, research agent, orchestration agent); human-in-the-loop Slack/email approval gates; automated failover and error recovery; comprehensive technical documentation.
  - *Duration:* 6–8 weeks.
  - *Estimated Delivery Hours:* 110–160 hours | Gross Margin: 70%.
- **Tier 3: Workflow Maintenance & Agent SLA Retainer (\$2,000–\$5,000/mo)**
  - *Deliverables:* Continuous workflow health monitoring, prompt performance tuning, third-party API deprecation updates, and 1 new automated workflow added every month.

### 3. Enterprise AI Development & Knowledge Systems (RAG)
- **Tier 1: Private VPC Architecture Discovery Blueprint (\$6,500)**
  - *Ideal Buyer:* CTO, CIO, VP Engineering.
  - *Deliverables:* Security and data sovereignty audit; document chunking & embedding evaluation; vector database sizing (Qdrant/pgvector); latency and token cost analysis; production technical architecture specification with zero data leakage guarantees.
  - *Duration:* 10 business days.
  - *Estimated Delivery Hours:* 28–35 hours | Gross Margin: 75%.
- **Tier 2: Production Private Enterprise RAG System (\$35,000–\$75,000)**
  - *Deliverables:* VPC-contained containerized deployment; automated pipeline ingesting internal PDFs, SharePoint, or Confluence docs; hybrid semantic search engine; custom Next.js knowledge assistant interface; role-based access control; hallucination evaluation ratchet.
  - *Duration:* 8–12 weeks.
  - *Estimated Delivery Hours:* 220–340 hours | Gross Margin: 68%.
- **Tier 3: Vector Indexing & AI Model Optimization Retainer (\$3,500–\$8,000/mo)**
  - *Deliverables:* Continuous re-indexing of newly published corporate documents, embedding drift monitoring, model latency optimization, and custom prompt evaluation updates.

### 4. Custom Web Platform & Application Development
- **Tier 1: Web Performance & Architecture Audit (\$4,000)**
  - *Deliverables:* Comprehensive audit of current platform speed, Core Web Vitals, security vulnerabilities, API bottlenecks, and an actionable Next.js modernization blueprint.
- **Tier 2: Custom Enterprise Web Platform (\$18,000–\$45,000)**
  - *Deliverables:* Decoupled Next.js/React web platform; mobile-responsive UI/UX design in Tailwind; secure customer/partner portal; full API integrations; SEO optimization; automated CI/CD pipeline.
- **Tier 3: Platform Maintenance & Agile Sprints Retainer (\$1,500–\$4,000/mo)**
  - *Deliverables:* Managed cloud hosting oversight, security patching, Core Web Vitals monitoring, and 10–20 hours/month of dedicated feature sprint development.
